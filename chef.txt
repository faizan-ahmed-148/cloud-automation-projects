what is cookbook ?
cookbook is a collection of recipe

what is recipe ?

repice is where we write code

Cookbook is upload on chef server

knife tool : to push cook book recipe on chef server

bootstarp : the process is chef server connect to node is bootstrap

chef super market : has all the code of cookbook or recipe

node : use chef client tool & ohai

Chef client : is to pull recpie from chef server

ohai : all the information are store in ohai basically it work as a database 
 

idempotency : chef use idempotency process it work as that chef server not take all the code again and again just pull the updated code

---the language we use in chef is ruby

WorkStation : Workstation are presonal computer or virtual server where all configuration code is created tested or changed

2) workstation communicate with the chef server using Knife tool

3)Knife : knife is command line tool that upload the cookbok in the server

Chef Server : chef server is the middle man between workstation and node

2) all cookbok are stored here

3) server may be hosted or locally or remote

Node : Node are the system where you applied your code 
ohai : fetches the current state of the node is located 
chef cliet : node is communicate with chef server using chef client tool
