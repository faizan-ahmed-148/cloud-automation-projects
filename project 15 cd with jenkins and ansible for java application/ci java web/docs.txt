---- scenerio

. agile sdlc 
. developer make regular code changes
. these commit need to be tested & build
. usually buil & release Team will do this job
. or developer responsibility to merge an integrate code


----- problems
. in an agile sdlc there will be frequent code changes
. not so frequently code will be tested
. which accumulates bugs and error in the code
. developer need to rework to fix these bugs and error
. manual build & relese process inter team dependencies

----- Solution
. regular build & tet for every time
. automated process
. notify for every build status
. fix code if bugs or error found instatly rather thn waiting

this process is called continuos integration
