--------------continuos integration on aws -----------------

--- Scenario

. agile sdlc
. developer make regular code change
. these commit needs to be build and tested
. usually build & release team will do this job
. developer reponsibility to merge and integrate code
 

---- problems

. in an agile sdlc there will be frequent code
. not so frequently code will be tested 
. which accumulates bugs and error in code
. developers need to rework to fix these bugs
. manual build and release process
. inter team dependencies

---- solution

. build & test for every commit
. automated process
.notify every build status
. fix code if bugs or error found instantly rather than waiting

----- problem

. ci server maintenance
. operational overhead to maintain server like jenkins . nuxus, sonar, git

--- solution
. cloud service for ci to remove ops overhead

--- >AWs service

code commit --> version control system
code artifact --> maven repository for dependency
code build --> build service from aws
code deploy -> artifact deployment service
sonar cloud --> cloud base sonarqube
checkstyle --> code analysis from build job
code pipeline --> service to integrate all jobs together
