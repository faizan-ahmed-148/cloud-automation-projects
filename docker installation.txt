Docker components

FROM -> for basic image this command must be on top of the docker file

RUN -> toxecute command it will create a layer in immage

MAINTAINER -> Author/Owner/Decription

COPY -> copy file from local system (docker vm)
we need to provide source, dedtination

ADD -> similar to copy but it provide a feature to download files from internet also we 
extract file at docker image

EXPOSE -> to expose ports such as port 9090 for tomcatat port 90
for nigix etc

WORKDIR - > to set working directory for a container

CMD -> execute commands but during container creation

ENTRYPOINT -. similar to CMD but has high pririty over CMD

ENV -. environment variables

1) create a file named Dockerfile
2) Add instructions in Dockerfile
3) Build dockerfile to create image
4)Run image to Create Container
