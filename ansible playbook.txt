===============  Variable ============


--> ansible uses variable which are define previously to enable more flexibility in playbook and role they can be used to loop through a set of given values , access information like given values access various and replace the host name system and replace certain stringin template with specific value


now go to ansible server and create one playbook

vi cars.yml

[ansible@ip]# My variable playbook

-- hosts: demo
   user: ansible
   become: yes
   connection: ssh
   
   vars: 
        pkgname: httpd
   tasks: 
      - name: install httpd server
        action: yum name='{{pkgname}}' state=installed

now to execute playbook

[ansible@ip] ansible-playbook vars.yml


======================== handler section =====================
A handler is exactly  the same as a task but it will run when called by another task

or


handler are just like regular tasks in an ansible playbook but are only run if the task contains , but are only run if the task conta
ins a notify directive


[ansible@ip] vi handlers.yml

-- hosts: demo
   user: ansible
   become: yes
   connection: ssh
   
   vars: 
        pkgname: httpd
   tasks: 
      - name: install httpd server
        action: yum name='{{pkgname}}' state=installed
        notify: restart HTTPD
   handlers:
      - name: restart HTTPD
        action: service name='{{pkgname}}'state=restarted


now to execute playbook

[ansible@ip] ansible-playbook handlers.yml
