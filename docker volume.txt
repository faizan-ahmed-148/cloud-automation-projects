====================Docker volume================================

--> volume is simply a directory inside our container
--> firstly we have to declare this directory as a volume and then share volume
--> even if we stop container ,still we have access volume
--> volume will be created in one container
--> you can declare a directory as a volume only while sreating container

-->you canot create volume from existing container
--> you can share one volume across any number of container
--> volume will not be included when you update an image 

you can mapped volume in two ways

1) container == container
2) host == container


==========creating volume  from Dockerfile====================

creating a dockerfile and write

  FROM ubuntu
  VOLUME ["myvolume"]

then create image this dockerfile
--> docker build -t imagename .

now create container from this image & run
--> docker run -it --name container imagename /bin/bash

now share volumee with another container

--> docker run -it --name container2(new)  --privileged=true --volumes-from yourcontainer(which have volume)


Now after creating containerw, myvolume1 is visible whatever you in one Volume cansee from another

touch /myvolume1
